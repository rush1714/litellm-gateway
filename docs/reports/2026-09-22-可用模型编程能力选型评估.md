# 非 GPT/Claude 模型的编程与架构能力选型评估

- **评估日期**：2026-09-22
- **评估范围**：本网关 `model list` 中除 GPT 系列与 Claude 系列之外的全部可用模型
- **评估目标**：在代码能力、架构能力、复杂系统设计能力三个维度上，找出最接近 GPT / Claude 旗舰的替代品
- **数据来源**：Google DeepMind 模型卡、Google 官方博客、Mistral 官方文档、NVIDIA build.nvidia.com 模型卡、Meta MODEL_CARD、IBM Granite 官方页、arXiv 2607.02770（Gemma 4 技术报告）、swebench.com 官方榜、llm-stats.com、Artificial Analysis、DataCamp、Layer3Labs、36氪

> **数据可信度声明**：本报告中的基准分数为**引用来源的实测/自报值**（标注 A 类）；综合评分为**基于这些数据的定性判断**（标注 C 类），不是任何榜单的官方分数。所有"未获取到公开数据"的项已显式标注 ⚠️，未做任何推测填充。

## ⚠️ 先说两个会改变结论的发现

### 发现 1：Gemini 3.8 Flash 已发布，明显强于你当前配置的 3.7 Flash，但网关里没接

Google 官方博客与 DeepMind 模型卡均于 **2026-09-02** 发布 Gemini 3.8 Flash。它的官方对比表里直接放进了 Claude Opus 5 和 GPT-5.6 Sol（真旗舰，不是 Terra / Sonnet 这类次旗舰），而且**在两项编程基准上反超了它们**：

| 官方基准（DeepMind 模型卡，2026-09） | **3.8 Flash** | 3.7 Flash | Claude Opus 5 | GPT-5.6 Sol |
| :--- | :--- | :--- | :--- | :--- |
| DeepSWE v1.1 | **73.7%** | 65.3% | 74.0% | 72.7% |
| Terminal-bench 2.1 | **89.4%** | 85.8% | 89.1% | 88.8% |
| GDPVal-AA v2（Elo，知识工作密度） | 1545 | 1482 | **1824** | 1710 |
| OSWorld-2.0 | 59.0% | 50.6% | **75.4%** | 62.6% |
| Terminal-bench 4.0 | 19.1% | 11.2% | **51.8%** | 37.3% |

**这是你当前能拿到的、最接近旗舰的选项**，且定价 $0.75 / $3.75 每百万 token（优惠至 2026-12-31），约为 Claude Opus 5 输出价的 1/6.7。建议尽快确认上游 ICA 网关是否已支持 `gemini-3.8-flash` 这个 ID。

> 附带提醒：Arena 上有化名 `gemini-3.8-flash` 的匿名模型被自媒体广泛传为 Gemini 4 Pro（代号 Argon），流传 DeepSWE 88.7% 等数据（智源、网易、钛媒体，2026-09-18~21）。**全部为泄露传闻，无任何官方来源，不可用于选型。** Gemini 4 的官方状态是：Pichai 在 2026-07-27 Q2 财报会确认处于预训练中，预计 2026 年 11–12 月发布。

### 发现 2：`mistral-medium-2505` 已于 2026-08-30 退役，但它是你 yaml 里 5 条 fallback 链的一环

Mistral 官方文档「Deprecated & retired models」页明确：`mistral-medium-2505` 停用日 **2026-05-21**、退役日 **2026-08-30**，替代者为 Mistral Medium 3.5。今天是 2026-09-22 —— **已过退役日 23 天**。

在你的 `config/litellm.yaml` 中，它出现在：
- `model_list` 第 51 行，注释标注为 "T1: Closest to Claude Sonnet coding & technical design"
- `fallbacks` 中 `gemini-3.7-flash`、`gemini-3.6-flash`、`meta-llama/llama-4-maverick-*`、`llama-4-maverick`、`llama` 五条链的降级目标
- `context_window_fallbacks` 第 380 行作为源模型

**风险**：一旦 3.7 Flash 请求失败，第一顺位降级会打到一个已退役的模型上，导致二次失败后才继续降级，白白吃掉一次 `num_retries`（当前配置为 2）和超时预算（180s）。

它的继任者 **Mistral Medium 3.5**（2026-04-28 发布，128B，256K 上下文，支持 `reasoning_effort` 可调）SWE-bench Verified **77.6%**（Mistral 官方 + HF 模型卡 2026-04-29），相比 2505 的 LiveCodeBench 30.3% 是彻底的代际跃迁。

### Llama 4 Maverick 17B-128E Instruct FP8（2025-04 发布）

## 四、与 GPT / Claude 旗舰的真实差距（你最关心的问题）

以 2026-09 当前旗舰为参照：

| 旗舰 | 关键成绩 |
| :--- | :--- |
| **Claude Opus 5** | SWE-bench Verified **96.0**（Anthropic 自报，2026-07-24/28，尚未进 llm-stats 排名列表）｜SWE-Bench Pro 79.2（第 2）｜DeepSWE 74.0%｜Terminal-bench 2.1 = 89.1%｜GDPVal-AA v2 = **1824**｜Terminal-bench 4.0 = **51.8%** |
| **Claude Fable 5** | SWE-bench Verified 95.0（llm-stats 第 1）｜SWE-Bench Pro **80.3**（第 1） |
| **GPT-5.6 Sol** | SWE-Bench Pro 64.6（第 6）｜DeepSWE 72.7%｜Terminal-bench 2.1 = 88.8%｜GDPVal-AA v2 = 1710｜Terminal-bench 4.0 = 37.3% |
| **Gemini 系最好成绩** | SWE-bench Verified：**Gemini 3.1 Pro = 80.6%，第 8**（3.7/3.8 Flash 完全不在榜上）｜SWE-Bench Pro：**Gemini 3.6 Flash = 58.7%，第 12** |

### 差距的三条结论

1. **在"纯写代码 / 长周期工程"这条线上，Flash 已经真正追平甚至局部反超旗舰。**
   Gemini 3.8 Flash 的 DeepSWE 73.7% 只比 Claude Opus 5 低 **0.3pp**、高于 GPT-5.6 Sol 的 72.7%；Terminal-bench 2.1 = 89.4% **直接超过两者**（89.1% / 88.8%）。3.7 Flash 的 FrontierCode 43.6% 和 WebDev Arena 1588 也已反超 Claude Sonnet 5 与 GPT-5.6 Terra。**日常写代码、改 bug、做前端，你用 Flash 不会有明显体感损失。**

2. **但在"架构判断与开放式规划"上差距依然很大，而且越开放掉得越快。**
   GDPVal-AA v2（知识工作密度）上 3.8 Flash 只有 1545，Opus 5 是 1824，**差 279 Elo**；OSWorld-2.0 差 16.4pp；Terminal-bench 4.0（更难的 agentic 版本）差 **32.7pp**（19.1% vs 51.8%）。3.7 Flash 在 Agent's Last Exam 上 26.3% 落后 Sonnet 5 的 33.3%。
   **这意味着**：让 Flash 实现一个你已经想清楚的方案 → 很好用；让 Flash 替你做技术选型、拆系统边界、定演进路线 → 它的判断密度明显不如旗舰，**架构决策仍需你自己把关**。

3. **别指望 1M 上下文能一次性喂进整个代码库。**
   Gemini 3.6 Flash 的 GDM-MRCR v2 在 128k 是 91.8%，但**在 1M 点态只有 54.0%**。标称窗口和有效检索是两回事。做全仓级架构分析时，仍需人工切分上下文或先做检索收敛。（3.7 Flash 的 128k = 97.0% 是组内最好，但 1M 段的有效性数据未获取到。）

## 五、给你的网关的具体行动建议
